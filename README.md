## 🚀 Key Features

- **Dynamic Liquid Fluid Simulation:** 60FPS high-performance 2D fluid dynamics canvas running background particle physics with adaptive resolution scaling.
- **3D Gyroscopic Tilt & Specular Glare:** Native CSS `transform3d` physics engine projecting real-time directional specular light highlights across glassmorphic panels.
- **Zero-Dependency Architecture:** 100% vanilla JavaScript, native CSS, and semantic HTML5. No bloated UI frameworks, no tracking beacons, no external CDNs.
- **Full-Spectrum Mobile Responsiveness:** Custom 2-column modal filters, fluid typography clamps (`clamp()`), and touch-optimized micro-interactions.
- **Strict Content-Security-Policy (CSP):** Hardened against DOM XSS, data exfiltration, and unauthorized script injection.
- **Embedded Dossier & CV Engine:** Direct one-click access to official PDF resume and verifiable offensive engagement track records.

## 🔒 Security Hardening & Defense

This portfolio is built to reflect professional offensive security standards:
- **Zero Third-Party Scripts:** Eliminates third-party supply chain risks.
- **DOM XSS Sanitization:** RSS feed parsers and DOM injections pass through strict `escapeHTML()` and `sanitizeUrl()` filters.
- **Strict Origin Referrer:** Enforces `strict-origin-when-cross-origin` to prevent credential leakage.
- **CSP Headers:** Restricts script execution, connections, and frame embedding to authorized boundaries.
